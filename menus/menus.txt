# rpnCE menu tree, opened with MATH (HOME). MODE jumps to the MODE menu.
#
# The menu tree is derived from the menu definitions of RPN83P,
# Copyright (c) 2023 Brian T. Park, used under the MIT License.
#
# Format (2-space indentation):
#   group LABEL ID        a menu; its children are rows
#   row                   one screen row of up to 5 entries
#   item LABEL ID [CMD [ARG]]         a function
#   alt LABEL ALTLABEL ID [CMD [ARG]] a mode item; ALTLABEL shows when on
#   blank                 an empty slot
#   include FILE          read another menu file here (top level only)
# Each command binding is defined once, on its first ID occurrence; other
# menus reuse the ID. ARG defaults to 0. Unit bindings come from unit order.
# Items without CMD use UI handlers or remain unavailable.
# Labels have no spaces. Symbols are written as {name}:
#   {sq} {cube} {cuberoot} {root} {sigma} {to} {block} {mu} {deg}
#   {up} {down} {left} {times} {supx}
# After editing, run: python3 tools/genmenu.py
