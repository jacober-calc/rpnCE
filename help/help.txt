# rpnCE on-device reference (HELP, or 2ND CATALOG).
#
# Built into the RPNCEres appvar by tools/genres.py: after editing, run
#   python3 tools/genres.py
# and rebuild both the program and resource appvar. Pages are separated
# by a line of three dashes. A page's first line is its title; each page
# has at most 8 lines, title included, of at most 44 ASCII characters.
# Lines starting with # are comments. Keep titles numbered in page order
# and the ABOUT version in sync with src/core/version.h.

# value-type and status pages. ABOUT is last (UP here reaches it).

HELP 01/26 - USING HELP / MENUS
UP / DOWN: previous / next HELP page.
Pages wrap; UP here opens ABOUT.
ENTER, CLEAR, DEL or ON: close HELP.
Y= WINDOW ZOOM TRACE GRAPH: menu keys.
In menus, UP / DOWN changes the row.
ON: back one menu. MATH: HOME.
Full guide: GitHub repo > docs/USER_GUIDE.md
---
HELP 02/26 - THE RPN STACK
X is the bottom; Y, Z, T are above it.
Type a number; ENTER copies X into Y.
Next number replaces X after ENTER/CLX.
Otherwise, typing lifts old X into Y.
Unary math uses X; binary math uses Y,X.
Y-X and Y/X: the order matters.
Example: 2 ENTER 3 + 4 * gives 20.
---
HELP 03/26 - VARIABLES
STO + letter: store X (stack kept).
2ND RCL + letter: recall to X.
Use the key's green letter, e.g. A.
STO/RCL then + - * /: reg arithmetic.
. = i; 2ND . = register numbered by i.
VARS: UP/DOWN select, ENTER recalls.
Real/complex/unit/DATE values stay whole.

HELP 04/26 - KEY SHORTCUTS
MATH: HOME    MODE: settings
STAT: STAT    X,T,theta,n: UNIT
APPS: BASE    PRGM: HYP
2ND MEM: CLR; LIST: STK; CATALOG: HELP
VARS: variables; 2ND ENTRY: SHOW
2ND ANS: LASTX; 2ND UP/DOWN: brightness
2ND MODE / 2ND ON: save and quit

HELP 05/26 - MATH
X^3: cube X; cube-root key: cube root.
X-root-Y: X-th root of Y.
ATN2: angle of (x=X,y=Y), DEG or RAD.
2^X: power of 2; LOG2: log base 2.
LOGB: log of Y in base X.
E^X-: exp(X)-1; LN1+: ln(1+X).
RRES: negative Y root needs odd int X.
---
HELP 06/26 - NUM
%: Y*X/100; %CH: (X-Y)/Y*100; keeps Y.
GCD/LCM: common divisor / multiple.
PRIM: factor to X, old X to Y; 1=prime.
IP/FP: int/fraction; ABS: |X|; SIGN: sign.
FLR/CEIL/NEAR: down/up/nearest integer.
MOD: Y mod X; MIN/MAX: smaller/larger.
RNDF: display; RNDN: places; RNDG: digits.
---
HELP 07/26 - PROB
COMB: combinations, Y choose X.
PERM: permutations, Y taken X at a time.
N!: factorial of whole X, 0 through 69.
RAND: random number, 0 <= X < 1.
SEED: use X to restart random sequence.
Example: 5 ENTER 2 COMB gives 10.
Example: 5 ENTER 2 PERM gives 20.
---
HELP 08/26 - CPLX
REAL / IMAG: real / imaginary part of X.
CONJ: negate the imaginary part.
CABS: magnitude. CANG: angle in DEG/RAD.
Real X: IMAG=0, CANG=0; CABS=abs(X).
Even a negative real has CANG=0.
REAL extracts a real from complex a+i 0.
ENTER/rolls/STO/RCL/LASTX keep both parts.
---
HELP 09/26 - COMPLEX ENTRY
DEC: 3 2ND . 4 ENTER gives 3+i 4.
2ND . ENTER gives i; . is decimal key.
2 2ND APPS 90 ENTER: polar degrees.
Repeat 2ND APPS: toggle radian/degree.
DEL/CHS/dot/EE affect active component.
2ND . selects rectangular entry.
Input angle unit ignores DEG/RAD mode.
---
HELP 10/26 - COMPLEX ARITHMETIC
+ - * /, CHS, 1/X, square/cube/roots.
^ LOG LN 10^X e^X LOG2 2^X LOGB work.
Complex powers/logs use principal values.
Log/exp angles are radians in all modes.
CRES: sqrt(-4)=i 2; LN(-1)=i pi.
Trig/HYP/NUM reject complex operands.
Errors keep operands and LASTX.
---
HELP 11/26 - COMPLEX MODES
MODE row 2: RRES/CRES, RECT/PRAD/PDEG.
RRES: real inputs use real-domain rules.
CRES: allow supported complex results.
Explicit complex inputs work in either.
RECT: real i imaginary components.
PRAD/PDEG: magnitude < angle, rad/deg.
Modes are independent; CANG uses DEG/RAD.
---
HELP 12/26 - COMPLEX LINK
2ND X,T,theta,n (LINK) joins or splits.
RECT: real Y, imaginary X -> complex X.
Complex X -> real Y and imaginary X.
PRAD/PDEG: Y=magnitude, X=angle rad/deg.
Join drops stack; split lifts levels.
Example in RECT: 3 ENTER 4 2ND LINK.
LINK also has typed DATE join meanings.
---
HELP 13/26 - TVM
N: payments; I%YR: annual rate (%).
PV: present; PMT: payment; FV: future.
Type then key stores; next key solves.
2ND + key recalls. Cash out: negative.
P/YR,C/YR: periods; BEG/END: timing.
CLTV: clear; IYR1/2: rate guesses.
TMAX: iteration limit; RSTV: defaults.
---
HELP 14/26 - BASE
DEC/HEX/OCT/BIN: number base.
ALPHA A-F in HEX; WSIZ: 1-44 bits.
LOGI: AND/OR/XOR/NOT/NEG.
ROTS: shifts/rotates; n uses X count.
BITS: clear/set/test/reverse/count bits.
BFCN: word + - * /; BDIV: quotient/rem.
BCFS: clear/set/test carry; WSZ?: size.
---
HELP 15/26 - HYP
SINH / COSH / TANH: hyperbolic functions.
ASNH / ACSH / ATNH: inverse functions.
ASNH accepts any real X.
ACSH needs X >= 1.
ATNH needs -1 < X < 1.
Example: 0 SINH gives 0.
Example: 0 COSH gives 1.
---
HELP 16/26 - STAT
Enter y ENTER x, then Sigma+ adds point.
Sigma- removes point; CL-Sigma clears.
ALL/LIN-Sigma: all 13 / six linear sums.
SUM/MEAN/WMN: sums/means/weighted means.
N: count; Sigma menu: recall each sum.
SDEV/PDEV: std dev; SCOV/PCOV: covariance.
CFIT: forecasts, slope, intercept, corr.
---
HELP 17/26 - CONV
->DEG: radians to degrees; ->RAD: back.
->POL: x=X,y=Y to radius=X,angle=Y.
->REC: radius=X,angle=Y to x=X,y=Y.
Polar angles use current DEG/RAD mode.
->HR: H.MMSS to hours; ->HMS: back.
HMS+ / HMS-: add / subtract H.MMSS.
Example: 1.30 ->HR gives 1.5 hours.
---
HELP 18/26 - CLR
CLX: clear X; next entry replaces X.
CLST: clear every stack level.
CLRG: clear A-Z, i and extra registers.
CL-Sigma: clear the statistics data.
CLTV: clear TVM; P/YR=C/YR=12, END.
CLD/CLEAR: dismiss a visible message.
No message? CLEAR twice clears stack.
---
HELP 19/26 - MODE
FIX/SCI/ENG: fixed/scientific/engineering.
Then digit; .digit=10-19; >=12=all.
RAD shown; else DEG. TINT: colors.
RSIZ/RSZ?: set/get registers (40-140).
SSIZ/SSZ?: set/get stack depth (4-12).
{..}/"..": raw/readable DATE values.
. / ,: decimal mark; grouping swaps.
---
HELP 20/26 - STK
DUP: copy X into Y, like ENTER.
R-up: top to X; roll other levels up.
R-down: X to top; roll others down.
DROP: remove X; stack drops.
X<->Y: swap X and Y; X<>: swap register.
( : R-down    ) : X<->Y    2ND } : DROP
2ND INS: DUP    2ND ANS: recall LASTX
---
HELP 21/26 - UNIT
Select a unit to attach it to X.
Choose same category to convert X.
+/- convert X to Y's unit; keep it.
Unit * number or unit / number: kept.
Unit / compatible unit: plain ratio.
UVAL: remove unit; UBAS: base unit.
TEMP/FUEL: conversion and rounding only.
---
HELP 22/26 - DATE
D/T/DT: date/time/date+time.
TZ/DZ: time zone / zoned date+time.
DR: duration; DW: day of week.
Choose {} key to enter; , splits fields.
Submenus: convert/extract/join/split.
EPCH: epoch; CLK: clock/time zones.
+/-: D,DW use days; T,DT,DZ use seconds.
---
HELP 23/26 - NUMBER TYPES
One level holds real/complex/unit/DATE.
STO/RCL/LASTX copy the complete value.
BASE words, STAT, TVM need plain reals.
Indices and sizes also need plain reals.
Complex a+i 0 still has complex type.
REAL extracts real; UVAL removes a unit.
Unsupported types: Err: Data Type.
---
HELP 24/26 - STATUS BAR
Always shown: ALL, FIXn, SCIn or ENGn.
SCI-/ENG-: all digits in SCI/ENG.
Implicit: DEG, DEC, RRES and RECT.
Optional: RAD, HEX/OCT/BIN, CF, CRES.
PRAD/PDEG: polar display and LINK.
2ND / A: pending 2ND / ALPHA key.
Clock uses HH:MM if date will not fit.
---
HELP 25/26 - NUMERIC LIMITS
Nonzero components: 1E-99 to <1E100.
Err: Overflow: value too large.
Err: Underflow: nonzero value too small.
Err: Precision: detected digit loss.
Errors keep operands and LASTX.
Intermediate limits can also cause errors.
CLEAR dismisses errors without clearing X.
