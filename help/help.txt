HELP 1/3 - KEYS
MATH: home    MODE: settings
STAT: STAT    X,T,theta,n: UNIT
APPS: BASE    PRGM: HYP
2ND MEM: CLR    2ND LIST: STK
2ND CATALOG: HELP    VARS: recall
2ND MODE or 2ND ON: quit
---
HELP 2/3 - STACK / REGISTERS
ENTER: duplicate X; type to replace X
( : roll down    ) : swap X and Y
2ND ANS: LASTX    DEL: edit / clear X
STO + letter: store X
2ND STO + letter: recall
STO + . : i    STO + 2ND . : (i)
PRIM: factor in X, original in Y
---
HELP 3/3 - UNITS
Choose a unit to attach it to X.
Choose a compatible unit to convert.
STO / RCL / X<> keep value and unit.
+ and - convert X to Y's unit.
%CH: (X - Y) / Y * 100, after conversion
TEMP / FUEL: convert or round only.
UVAL: remove unit    UBAS: base unit
